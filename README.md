# Анализ датасета Kaggle Game Arena

Лабораторная работа: анализ данных выступлений нейросетей (LLM) в игровой арене.

## Файлы
* `analysis.ipynb` — Jupyter-блокнот с кодом, графиками и выводами.
* `kaggle_game-arena_leaderboard.csv` — исходные данные.
* `requirements.txt` — зависимости.

## Что делает код
1. Загружает CSV, чистит лишние колонки.
2. Делает `pivot` (одна строка = одна модель).
3. Рисует Топ-10 моделей по Score.
4. Рисует график зависимости Score от количества матчей.
5. Считает корреляцию (проверка гипотезы).

**Итог:** гипотеза о связи количества матчей и итогового балла не подтвердилась (корреляция близка к нулю).

## Запуск
1. `pip install -r requirements.txt`
2. Открыть `.ipynb` и выполнить все ячейки.
